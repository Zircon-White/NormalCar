# AURELIS GT — 折面灰模

一个可直接在浏览器里查看的概念轿跑灰模。没有外部依赖，不需要联网，也不需要安装 Maya 或其他软件。

## 打开方式

双击 `index.html` 即可。

## 操作

| 操作 | 作用 |
| --- | --- |
| 鼠标左键拖拽 | 环绕观察 |
| 滚轮 | 缩放 |
| 点击车身/零件 | 选中并查看零件信息 |
| 选中后点「单独显示」 | 隔离查看该零件 |
| 拖动「拆解」滑杆 | 逐步展开 78 个独立零件 |
| 左右拖拆解滑杆同时点「拆解」 | 一键复位/展开 |
| 空格键 | 自动旋转 |
| R 键 | 重置视角 |
| Esc 键 | 取消选中 |

## 模型说明

- 程序化生成、平面着色的折面灰模，没有使用平滑曲面
- 4.6 m 车长、2.0 m 车宽、1.3 m 车高的双门概念 GT 比例
- 78 个独立零件、约 2.6 万个三角面
- 包含车身覆盖件、前后灯组、玻璃、轮毂/轮胎/制动、悬挂、V8 动力总成、底盘、内饰和空气动力学部件
- 车轮、车门、机盖、保险杠、灯组、内饰等均可独立选中、隐藏与拆解

## 文件

- `index.html` — 页面入口
- `styles.css` — 页面样式
- `js/geom.js` — 轻量几何构建工具
- `js/car.js` — 整车与零件模型
- `js/app.js` — 视图、交互与渲染

需要浏览器支持 WebGL；建议使用较新的 Chrome / Edge / Firefox。
